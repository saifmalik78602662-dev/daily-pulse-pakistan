# Daily Pulse Pakistan — Website (Express + SQLite backend)

A news website: black-theme frontend, Express.js backend, SQLite database,
server-rendered pages (so Google and no-JS browsers see real content),
admin dashboard (add / edit / delete articles), and a contact form that
emails **saifmalik78602662@gmail.com**.

## What's inside

```
daily-pulse-pakistan/
├── server.js              # Express server — all routes (pages + API)
├── render.js                # Server-side HTML templating (shared layout)
├── db.js                      # SQLite database (built into Node.js)
├── auth.js                      # Simple admin login/session handling
├── package.json
├── .env.example                    # Copy to .env and fill in your details
├── data/                              # daily-pulse.db (created on first run)
└── public/
    ├── admin.html                          # Admin dashboard (login, add/edit/delete)
    ├── privacy-policy.html                   # Privacy Policy
    ├── terms.html                              # Terms & Conditions
    ├── disclaimer.html                           # Disclaimer
    ├── styles.css                                  # Shared stylesheet
    └── 404.html                                      # Custom "page not found"
```

Note: the homepage, Articles listing, and individual article pages are
**not static files** anymore — they're generated by `server.js` /
`render.js` on every request, with real article content already in the
HTML. This is what fixes the "Loading…" issue and makes content visible
to search engines without relying on JavaScript.

## Running it

```bash
npm install
cp .env.example .env
# edit .env: set ADMIN_PASSWORD and (optionally) SMTP details
npm start
```

Then open `http://localhost:3000`. Admin dashboard: `http://localhost:3000/admin.html`.

## Deploying it (so it has a real public URL)

This is a Node.js app — it needs a host that runs Node, not a static host
like Netlify/GitHub Pages.

**Render.com (recommended, free tier):**
1. Push this project to a GitHub repository.
2. On Render: New → Web Service → connect the repo.
3. Build command: `npm install`  |  Start command: `npm start`.
4. Under Environment, add the same variables from `.env`.
5. Add a **Persistent Disk** mounted at `/opt/render/project/src/data` —
   otherwise the SQLite database resets every time Render restarts the service.
6. Deploy. You'll get a URL like `https://daily-pulse-pakistan.onrender.com`.

**Railway.app** works the same way — New Project → Deploy from GitHub →
add env vars → add a Volume mounted at `/app/data`.

Once deployed, visit `/sitemap.xml` on your real domain and submit that
URL in Google Search Console.
